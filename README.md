# OutBound 🚀
A compact, custom-built handheld ESP32-S3 cyberdeck featuring a 2.4-inch TFT display, an 8x8 LED matrix for notifications, and tactile physical controls—designed from scratch with hand-drawn paper schematics and 3D-printed enclosures.

---

## 🛠️ Hardware Specifications & Dimensions
* **Dimensions:** 9.2 cm x 6.7 cm (Compact handheld form factor)
* **Microcontroller:** UG LAND INDIA ESP32-S3 WROOM N16R8 CAM Board
* **Display:** 2.4-inch SPI TFT Display (ILI9341)
* **Status & Alerts:** MAX7219 8x8 LED Matrix Board
* **Audio:** MAX98357A I2S Audio Amplifier with speaker
* **Power:** 3.7V 2500mAh LiPo Battery with USB-C charging/flashing
* **User Inputs:** 
  * Rotary Thumb Wheel / Encoder
  * Dedicated Push Buttons (Navigation & Home)
